# Personal Expense Tracker

## About the Project
Personal Expense Tracker is a simple Python project that helps users record and manage their daily expenses. It stores expense details in a CSV file and allows users to view their expenses and check category-wise and monthly spending.

## Features
- Add new expenses
- View all recorded expenses
- Calculate total expenses
- View category-wise expense summary
- View monthly expense summary
- Save expenses in a CSV file
- Check invalid inputs

## Technologies Used
- Python 3
- Pandas
- CSV File
- VS Code

## Project Files
- `expense_tracker.py` – Main Python program
- `expenses.csv` – Stores expense records
- `README.md` – Project information

## How to Run

### 1. Install Python
Make sure Python is installed on your computer.

### 2. Install Pandas
Open the terminal and run:

```bash
pip install pandas
```

### 3. Run the Program
Open the project folder in VS Code and run:

```bash
python expense_tracker.py
```

## How It Works
The program displays a menu where users can select different options. Users can add expenses by entering the date, category, description and amount. The entered data is saved in a CSV file. Users can also view all expenses and check category-wise or monthly summaries.
